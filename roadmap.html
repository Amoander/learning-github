Credentials track

Optional certifications that line up with each phase. None are required to get hired; a strong GitHub history counts for more. Check them off as you earn them.

Phases 1–2

GitHub Foundations (GH-900)

Entry-level exam on Git basics, repos, branches, pull requests and Issues. A good first target once you've merged a pull request.

Phases 1–2

Python Institute PCEP, then PCAP

The standard entry-level and associate Python certifications, covering the language basics you'll use in every project.

Phase 3

GitHub Actions (GH-200)

Automating tests and workflows with CI. Pairs with getting your portfolio project's tests running on every push.

Phase 4

GitHub Advanced Security (GH-500)

Secret scanning and push protection, Dependabot and dependency review, and code scanning with CodeQL. Mirrors your security phase closely.

Aimed at security-focused roles; take it if you lean that way.
Phase 4

CompTIA Security+ and the OWASP Top 10

Security+ is the widely recognized general security foundation. The OWASP Top 10 isn't a cert, but employers expect you to know it.

Security+ is broader than coding; optional unless you want IT or security work.
Phase 5

AI-assisted development

No established certification exists for this yet. The proof is your work: clean commits, real tests, and code you can explain in your own words.
